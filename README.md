# bug.dr — landing page

Marketing site for bug.dr. Single page, App Router, Next.js 16 + React 19.

## Stack
- Next.js 16 (App Router) + React 19
- TypeScript, Tailwind CSS, framer-motion
- next/font: Inter (UI) + JetBrains Mono (code, wordmark)
- Tokens: `tailwind.config.ts` (colors, fonts, radii, shadows)

## Run

```bash
npm install
npm run dev      # http://localhost:3000 (3001 if 3000 is busy)
npm run build    # production build
npm start        # serve production build
```

## Brand tokens

| Token     | Hex       | Use                                            |
|-----------|-----------|------------------------------------------------|
| `bg`      | `#151618` | page background                                |
| `surface` | `#202226` | cards, panels, IDE                             |
| `border`  | `#383C43` | separators, inputs, code-line borders          |
| `action`  | `#8BACFF` | primary buttons, links, "." in wordmark, pass  |
| `text`    | `#F2F3F5` | body, headings, fail emphasis                  |
| `muted`   | `#ACB2BE` | secondary text, pending                        |

Status colors (pass/warn/fail) are **derived from the base palette**, not new hues:
- pass / healthy = `--action`
- pending / degraded = `--muted`
- fail / error = `--text` with thicker border

This is deliberate per design direction — the brand palette is the only palette.

## Responsive breakpoints checked
375 (mobile), 768 (tablet), 1280 (desktop), 1440 (wide).

## Accessibility
- Semantic landmarks (`<header>`, `<main>`, `<nav>`, `<section>`, `<footer>`)
- Visible focus ring (`focus-visible:ring-2 ring-action`)
- AA contrast on all text/background pairs in the palette
- `prefers-reduced-motion` disables all transitions and animations
