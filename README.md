# bug.dr : landing page

Marketing site for bug.dr. Single page, App Router, Next.js 16 + React 19.

## Stack
- Next.js 16 (App Router) + React 19
- TypeScript, Tailwind CSS, framer-motion
- next/font: Inter (UI) + JetBrains Mono (code, wordmark)
- Tokens: `tailwind.config.ts` (colors, fonts, radii, shadows)

## Run

```bash
npm install
npm run dev      # http://localhost:3000 (3001 if 3000 is busy)
npm run build    # production build
npm start        # serve production build
```

## Brand tokens

| Token             | Hex       | Use                                              |
|-------------------|-----------|--------------------------------------------------|
| `bg`              | `#151618` | page background                                  |
| `surface`         | `#202226` | cards, panels, IDE                               |
| `border`          | `#383C43` | separators, inputs, code-line borders            |
| `action`          | `#8BACFF` | primary buttons, links, "." in wordmark, pass    |
| `text`            | `#F2F3F5` | body, headings, fail emphasis                    |
| `muted`           | `#ACB2BE` | secondary text, pending                          |
| `good`            | `#7BD88F` | feedback card: "you" beats top performers        |
| `warn`            | `#F2C14E` | feedback card: "you" is up to 2x worse than top  |
| `bad`             | `#FF6B6B` | feedback card: "you" is more than 2x worse       |
| `scoreStrong`     | `#88C9A1` | scorecard: scores 90+                            |
| `scoreWarm`       | `#E0B265` | scorecard: scores below 80                       |
| `diffEasy`        | `#88C9A1` | difficulty: Easy                                 |
| `diffMedium`      | `#E0B265` | difficulty: Medium                               |
| `diffHard`        | `#E58958` | difficulty: Hard                                 |
| `diffImpossible`  | `#E5739A` | difficulty: Get a job                           |

Status colors (pass/warn/fail) are split into two families:
- The AI feedback card uses `good` / `warn` / `bad` so the "your value
  vs top performers" comparison reads at a glance.
- The scorecard uses `scoreStrong` / `action` / `scoreWarm` for the same
  thresholds (90+, 80 to 89, below 80) but in the muted style of the
  accent so the card stays in the brand palette.

## Responsive breakpoints checked
375 (mobile), 768 (tablet), 1280 (desktop), 1440 (wide).

## Accessibility
- Semantic landmarks (`<header>`, `<main>`, `<nav>`, `<section>`, `<footer>`)
- Visible focus ring (`focus-visible:ring-2 ring-action`)
- AA contrast on all text/background pairs in the palette
- `prefers-reduced-motion` disables all transitions and animations
- `prefers-reduced-transparency` makes frosted surfaces opaque
- `role="meter"` + per-row `aria-label` on every scorecard bar
- `<input>` autocomplete hints on the waitlist form
